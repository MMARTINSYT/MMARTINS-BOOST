# Bibliotecas de terceiros — MMARTINS BOOST

O MMARTINS BOOST utiliza componentes de código aberto desenvolvidos por terceiros.

## Qt / PySide6

Interface gráfica baseada em Qt for Python (PySide6), utilizando Qt 6.12.0.

O Qt for Python é disponibilizado sob licenças de código aberto LGPLv3/GPLv3 ou licença comercial, conforme os componentes e condições aplicáveis.

Informações oficiais:
https://doc.qt.io/qtforpython-6/

Licenciamento:
https://www.qt.io/development/open-source-lgpl-obligations

## FFmpeg

O aplicativo utiliza FFmpeg para recursos relacionados a vídeos.

Versão identificada: FFmpeg 7.1, compilação Essentials da gyan.dev.

A compilação identificada utiliza `--enable-gpl` e `--enable-version3`, estando sujeita à GPLv3.

Projeto oficial:
https://ffmpeg.org/

Informações de licenciamento:
https://ffmpeg.org/legal.html

Distribuidor da compilação:
https://www.gyan.dev/ffmpeg/builds/
